- 所有对外暴露的 Pages Function 均使用 ESM `export async function onRequest(context)` 形式，并通过 `context.env.DB` 条件访问 D1，确保无绑定时优雅降级。
- 所有数据库操作包裹在 try/catch 中并以 `.catch(() => {})` 静默失败，保证分析写入或查询异常不会中断页面正常渲染。
- HTML 页面统一通过 `<meta name="robots">`、Open Graph 标签和 `<link rel="canonical">` 声明 SEO 元信息，并在 `<head>` 内联初始化主题（`data-theme`）。
- 导航链接统一指向 `/home/`、`/docs/`、`/tutorials/`、`/alpha-library/`、`/research-lab/` 等规范路径，具体 URL 重写交由 Cloudflare 的 `_redirects` 文件集中管理。
