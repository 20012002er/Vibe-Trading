- 多语言资源按功能域（app/layout/runtime/scheduled/reports/connection 等）组织为嵌套 JSON key，并通过 `{{count}}` / `{{when}}` 等插值变量传递动态内容。
- 新增语言时仅在 `SUPPORTED_LANGUAGES` 数组与对应 `locales/*.json` 文件中登记，非英文资源统一通过 `localeLoaders` 中的动态 import 懒加载，避免首包膨胀。
- RTL 支持通过 `SUPPORTED_LANGUAGES[].dir` 标记并由 `isRtl` / `applyDocumentDirection` 统一处理，组件侧无需感知语言方向。
- 通用组件采用受控 props 模式（如 `open` + `onConfirm`/`onCancel`），内部不持有业务状态，仅负责 DOM 行为（Portal、焦点环、键盘事件）。
- 样式全部使用 Tailwind 语义化 token（如 `bg-primary`、`text-destructive`、`bg-background`），禁止硬编码色值，以配合主题切换。
