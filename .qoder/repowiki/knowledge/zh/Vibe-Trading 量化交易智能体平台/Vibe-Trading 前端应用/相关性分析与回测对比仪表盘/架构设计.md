模块由两个页面组件与一组 ECharts 图表子组件构成：`Correlation.tsx` 作为相关性分析入口，通过 `api.getCorrelation` / `getCorrelationRegime` 并行拉取相关系数矩阵与回归态数据，渲染 `CorrelationMatrix`（热力图）与 `RegimeTimeline`；`Compare.tsx` 作为回测对比入口，使用 `api.listRuns`、`api.getRun` 分别加载左右两侧运行的指标与权益曲线，并通过内嵌的 `EquityChartOverlay` 将两条曲线叠加展示，同时以表格形式逐项比较 METRICS 定义中的指标并标注优劣方向。所有图表均位于 `components/charts/` 下，每个图表组件遵循统一模式：基于 `useRef` + `useEffect` 调用 `@/lib/echarts` 初始化 ECharts，通过 `getChartTheme()` 获取主题色，使用 `ResizeObserver` + `requestAnimationFrame` 节流 resize，并在卸载时 `chart.dispose()`。页面层仅负责状态管理与 API 调用，图表层只消费 props 渲染，依赖方向单向为 pages → charts → @/lib/*。
