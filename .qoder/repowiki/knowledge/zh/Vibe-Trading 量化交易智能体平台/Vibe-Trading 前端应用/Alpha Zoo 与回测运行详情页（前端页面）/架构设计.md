本模块由三个独立的路由页面组件组成：
- `Home.tsx`：纯展示型首页，通过 `react-i18next` 的 `useTranslation` 渲染功能特性与步骤卡片，并导航到 `/agent`。
- `AlphaZoo.tsx`：单文件多视图路由聚合器，根据 `pathname` 和 `useParams` 在 `BrowseView`、`DetailView`、`BenchView`、`CompareView` 之间切换；通过 `@/lib/api` 调用后端 REST/SSE 接口，使用原生 `EventSource` 订阅 alpha 基准测试的 `progress/result/done/error` 事件流（注释明确说明不使用共享 `useSSE` hook 以避免事件类型硬编码过滤），并通过 ECharts + `ResizeObserver` 渲染按主题分组的堆叠柱状图。
- `RunDetail.tsx`：基于 `runId` 参数加载回测数据，采用“懒加载 + 缓存”模式——初始仅拉取 `chart_payload: summary`，按需通过 `api.getRun({ chart_symbol })` 增量获取各标的 K 线，并用 `chartCacheRef` 与 `runGenerationRef` 防止竞态；以 Tab 组织 Chart / Trades / Studio / Validation / RunCard / Code 六个子面板，图表复用 `CandlestickChart`、`EquityChart`、`ValidationPanel` 等共享组件，代码片段通过 `ReactMarkdown` + `rehype-highlight` 高亮显示。
依赖方向单向向外：页面 → `@/lib/api`（REST+SSE）、`@/components/charts/*`（图表）、`@/i18n`（国际化文案）、`sonner`（通知）。
