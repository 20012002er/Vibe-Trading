模块由三个文件构成应用启动的最小闭环：`main.tsx` 作为唯一入口，通过 `createRoot` 挂载 `<StrictMode>` + `<ErrorBoundary>` + `<RouterProvider>` + `<Toaster>` 的根树，并在空闲时预取 `MiniEquityChart` 组件；`router.tsx` 使用 `createBrowserRouter` 声明所有页面路由，所有页面组件均通过 `lazy(() => import(...))` 动态导入并由 `wrap` 包裹在 `Suspense` 中，统一以 `Layout` 作为外层布局容器；`index.css` 基于 Tailwind 的 `@tailwind base/components/utilities` 指令注入全局样式，并通过 CSS 变量在 `:root` 与 `.dark` 下分别定义浅色/深色两套设计令牌（背景、前景、卡片、主色、语义色、图表色等），同时提供滚动条、表格、KaTeX、消息入场动画及 RTL 镜像等全局样式增强。依赖方向单向：`main.tsx` → `router.tsx` → `@/pages/*`，样式由 `index.css` 被入口引入后全局生效。
