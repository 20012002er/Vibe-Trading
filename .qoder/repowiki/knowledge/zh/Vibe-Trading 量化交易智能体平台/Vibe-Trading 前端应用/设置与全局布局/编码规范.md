- 表单采用受控组件模式：将后端返回的配置映射为本地 form state（如 `toForm`、`formFromConfig`），提交时再序列化回 API 所需结构。
- 异步副作用统一用 `Promise.allSettled` 并发请求多个接口，并在 `.finally` 中清理 loading 状态，错误分支区分认证失败与普通错误并配合 `toast.error` 提示。
- UI 文案全部通过 `react-i18next` 的 `t(...)` 获取，键名按模块前缀组织（如 `settings.*`、`layout.*`、`qveris.*`、`connection.*`）。
- 输入字段样式通过局部常量 `fieldClass`、`labelClass`、`hintClass` 集中定义，保证 Settings 与 QVerisSettings 中表单控件视觉一致。
- 桌面端特有逻辑通过 `window.vibeDesktop` 存在性判断进行条件分支，避免在非桌面环境下调用不存在的方法。
- 自定义下拉/选择器组件（如 `ModelPicker`、`LanguageSwitcher`）遵循 WAI-ARIA 组合框/列表框模式，使用 `role`、`aria-expanded`、`aria-controls`、`aria-activedescendant` 等属性保障键盘与屏幕阅读器可用。
