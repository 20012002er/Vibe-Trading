- 页面与组件采用按功能域拆分目录（pages、components/{charts,chat,common,layout,settings}），每个目录内可附带同名 __tests__ 子目录存放单元测试
- 跨页面共享能力集中在 src/lib 与 src/stores，页面仅消费 API 与 store 而不直接持有网络或状态逻辑
- 国际化文案统一放在 src/i18n/locales/*.json，通过 i18n/index.ts 初始化后由组件使用 i18next hook 读取
- 图表类组件封装在 components/charts 下，统一基于 ECharts 并通过 lib/echarts.ts 与 chart-theme.ts 共享配置
