- 每个可插拔组件（DataLoader、Engine、Optimizer）均通过 ABC/Protocol 暴露最小接口，新增实现只需继承基类并覆写少数方法。
- 数据源通过 `loaders.registry` 注册并按 source/market 名称动态解析，避免硬编码分支。
- 配置校验集中在 Pydantic model（如 `BacktestConfigSchema`）中使用 `field_validator`/`model_validator` 声明式检查，而非运行时 if 判断。
- 对外部 API 调用统一使用 `retry_with_budget` + `check_budget` 包装，以 wall-clock deadline 限制重试总时长。
- 指标计算函数（年化因子、换手率、收益统计）按 source×interval 查表驱动，新增数据源只需扩展映射表。
- 策略代码在 import 前经 AST 扫描拒绝 import-time 执行，并在运行路径上拒绝网络/进程/文件写入/反射等危险操作，形成双层沙箱。
