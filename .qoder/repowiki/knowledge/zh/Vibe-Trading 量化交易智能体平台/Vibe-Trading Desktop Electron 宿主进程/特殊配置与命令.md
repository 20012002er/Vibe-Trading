开发运行需先构建前端并安装 Python 环境：`python -m venv .venv && pip install -e . && cd frontend && npm ci && npm run build`，再进入本目录执行 `npm start`。CI 冒烟套件通过 `npm run smoke:lifecycle` 依次验证本地化消息、优雅关闭、认证与父进程死亡路径。Windows 打包命令：`npm run pack:win`（dir）、`npm run installer:win:review`（未签名 NSIS）、`npm run installer:win:signed`（需 Authenticode 签名）。可通过设置 `VIBE_TRADING_EXECUTABLE` 指定开发后端可执行文件。
