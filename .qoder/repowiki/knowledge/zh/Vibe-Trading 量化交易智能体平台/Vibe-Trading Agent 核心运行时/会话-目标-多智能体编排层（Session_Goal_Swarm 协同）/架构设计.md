三层协作：session 作为入口编排用户消息到策略执行的完整循环，并通过 SSEEvent 事件总线对外暴露实时状态；goal 为会话级金融研究目标提供状态机、证据账本与审计，其 context 模块生成注入模型提示的目标上下文，被 agent loop 在推理时读取；swarm 提供基于 YAML preset 的多智能体 DAG 引擎，由 agent 的 tool 调用触发，运行时按拓扑分层调度 worker 并行执行并将结果写回 session 的消息流。三者通过共享的 SQLite 存储（session.store、goal.store、swarm.store/task_store）和 src.session.events.SSEEvent 事件总线解耦，API 路由（sessions_routes.py、swarm_routes.py）与 channels/websocket.py 作为外部接入点消费这些组件，agent/loop.py 则把 goal 上下文与 swarm 工具调用嵌入主 AgentLoop。
