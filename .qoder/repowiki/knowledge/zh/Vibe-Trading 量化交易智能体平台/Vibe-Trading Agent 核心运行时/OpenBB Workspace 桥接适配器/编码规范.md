- 对外部/可选依赖采用延迟 import + try/except 包裹（如 routes 中的 `api_server` 模块、`__init__` 中的 `.routes` 导入），确保可选功能失败时优雅降级而不影响核心服务。
- 对来自外部 SDK 的任意结构使用 `getattr(obj, attr, None)` 或 dict.get 的安全读取模式（`_safe` 辅助函数），避免属性/键不存在导致异常。
- 所有用户可见文本输出均通过 `openbb_ai.helpers.message_chunk` 与 `reasoning_step` 构造标准 SSE 对象，而非直接拼接字符串。
- 长文本输入统一施加字符预算限制并通过截断标记（如 `DATA_TRUNCATION_MARKER`、`...`）提示裁剪，防止大附件撑爆首轮 LLM 调用。
- 事件处理采用白名单策略：显式列出的事件类型被映射，未知事件默认静默吞掉并 debug 记录，避免内部噪声泄露到 Workspace。
- 适配器方法通过 Optional 参数注入协作对象（`WorkspaceContextInjector`、`SSEEventMapper`），便于测试替换与行为定制。
