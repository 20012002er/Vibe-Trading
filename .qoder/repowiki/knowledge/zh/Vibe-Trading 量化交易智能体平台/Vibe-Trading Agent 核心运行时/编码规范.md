- 所有可插拔能力（工具、通道、因子、技能、券商连接器）均通过包内 `__init__.py` 或独立 registry 模块集中注册，供上层按需发现而非硬编码导入。
- 配置统一经 `src/config/accessor.get_env_config()` 读取，并以 dataclass schema 校验，禁止直接散落 os.environ。
- 对外 API 路由集中在 `src/api/` 下按域拆分文件（sessions/runs/channels/live/swarm/settings），统一使用 `security.py` 中的认证装饰器与 SSE ticket 机制。
- 持久化采用 JSON/Markdown/SQLite 三种后端并存模式，并在 `strategy_store/`、`session/store.py`、`scheduled_research/store.py` 等模块中复用同一套原子写入与迁移接口。
- 异步事件通过 `channels/bus/` 的 queue 与 signal 机制在各子模块间解耦传递，避免直接耦合调用。
