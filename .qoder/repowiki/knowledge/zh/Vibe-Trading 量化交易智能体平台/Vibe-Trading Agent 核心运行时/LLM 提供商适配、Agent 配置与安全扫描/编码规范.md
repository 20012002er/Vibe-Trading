- 对可选第三方依赖（langchain-openai、langchain-anthropic、httpx、dotenv、yaml）统一采用顶层 try/except 延迟导入并在缺失时置为 None，避免硬依赖导致启动失败。
- 所有外部敏感信息（API Key、base URL、.env 路径、代理地址）在日志中一律通过 `_redact_*` 辅助函数进行脱敏后再输出，禁止直接记录明文值。
- 配置模型统一继承 `ConfigBase`，使用 `alias_generator=_to_camel` 与 `populate_by_name=True` 同时接受 snake_case 与 camelCase 键，并通过 `model_validator(mode='after')` 执行跨字段业务校验（如 live broker 通配工具拒绝、OAuth 必须 HTTPS）。
- Provider 行为差异通过 `ProviderCapabilities` 数据类集中声明并由 `get_provider_capabilities` 按 provider/model 解析，而非在各适配器内硬编码分支。
- 配置加载函数对读错/解析失败的配置文件一律 fallback 到空默认对象并记录 warning，确保 Agent 启动不因配置错误而崩溃。
- 安全扫描器以不可变 `InjectionRule` 数据类注册规则，扫描结果追加到 payload 的 `security_warnings` 列表，文本经 `neutralize_special_tokens` 原地中和而不丢弃原始内容。
