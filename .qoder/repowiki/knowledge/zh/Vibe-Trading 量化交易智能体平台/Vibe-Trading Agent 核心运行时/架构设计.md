本模块以 `agent/loop.py` 中的 AgentLoop 作为主执行循环，通过 `providers/` 接入 LLM、通过 `tools/` 注册的工具集驱动思考-行动-观察闭环；`session/` 维护对话上下文并持久化到 `memory/` 的 Markdown 文件型存储，`goal/` 与 `governance/` 用账本记录研究目标与审计清单，`swarm/` 在单会话基础上升级为跨团队 DAG 工作流。对外暴露面由 `api/`（FastAPI 路由）和 `channels/`（IM 适配器 + channelsui WebUI WebSocket）共同构成，二者均通过 `config/` 的结构化配置加载与 `security/` 的安全策略进行鉴权与访问控制。金融领域能力以可插拔方式注入：`factors/` 与 `hypotheses/` 提供因子与假设注册中心，`quantlib/` 沉淀数学原语，`skills/` 以 SKILL.md 文档+示例引擎形式被 Agent 动态加载，`trading/` 聚合券商连接器并通过 `live/` 的 Mandate/OrderGuard/KillSwitch 门控进入实盘。启动流程由 `preflight.py` 统一校验 LLM、数据源连通性，再由各子模块按需在运行期懒加载，避免冷启动依赖。
