该模块是一个纯文档+示例的“技能”目录，没有 Python 包代码或构建脚本；每个子目录代表一个独立技能，通过统一的 `SKILL.md` YAML front matter（`name`/`description`/`category`）被上层 agent 发现并加载。

- 目录按能力域划分：`data-source`（eastmoney、tushare、yfinance、okx-market、sec-edgar、qveris 等）、`strategy`/`research`（chanlun、candlestick、ichimoku、harmonic、multi-factor、strategy-dev-manager 等）、`risk`/`macro`/`fundamental` 等主题。
- 每个技能内部采用一致的三件套结构：`SKILL.md`（入口说明 + 依赖安装 + 快速上手）、可选 `references/`（按主题分文件夹的详细接口/概念文档）、可选 `scripts/`（调用第三方 API 的最小可运行示例）、可选 `example_signal_engine.py` / `templates/*.py`（遵循统一 `SignalEngine.generate(data_map)` 契约的信号实现）。
- 信号引擎契约由 `strategy-dev-manager/SKILL.md` 明确定义：类名 `SignalEngine`、无参构造、`generate(data_map: dict[str, pd.DataFrame]) -> dict[str, pd.Series]`，返回值约定 `1=做多、-1=做空、0=观望`，并被多因子组合引擎 `multi-factor/zoo_signal_engine.py` 复用。
- 依赖方向单向：技能文档仅引用自身 `references/` 与 `scripts/`，不反向依赖 agent 源码；实际工具调用通过相对路径（如 `eastmoney/references/...`）由上层 `read_file` 工具解析。
- 多因子组合通过 `zoo_signal_engine.py` 的 `ZooSignalEngine` 将多个 alpha 计算结果做横截面 z-score 加权合成，支持 top-N/bottom-N 离散化输出。
