本模块是 agent 的消息通道层，每个文件对应一个平台（telegram.py、slack.py、discord.py、wecom.py、weixin.py、feishu.py、msteams.py、matrix.py、napcat.py、qq.py、whatsapp.py、mochat.py、email.py、websocket.py），均继承自 `src.channels.base.BaseChannel` 抽象基类，实现统一的 `start()`/`stop()`/`send()` 生命周期与可选的 `send_delta()`/`send_reasoning_delta()` 流式接口。各适配器通过 Pydantic `BaseModel` 定义自身配置（如 `TelegramConfig`、`SlackConfig`、`WebSocketConfig`），并在 `default_config()` 中暴露默认值；入站消息经平台 SDK 解析后调用基类的 `_handle_message()` 完成权限校验（allow_from / pairing store）并推送到 `MessageBus`，出站消息则通过各自 SDK（python-telegram-bot、slack_sdk Socket Mode、websockets、httpx 等）发送。模块依赖方向单向：适配器 → base + bus.events/queue + utils（split_message、get_media_dir、validate_url_target），不反向依赖上层业务逻辑。websocket.py 同时充当内置 WebUI 服务端，除通用 Channel 职责外还处理 token 签发、工作区隔离与 UI 事件转发。
