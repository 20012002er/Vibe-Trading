- 新增 IM 平台以继承 BaseChannel 并在 channels 包下以同名模块注册，由 registry 自动发现并纳入 ChannelManager 生命周期管理
- 渠道间通信统一使用 MessageBus 的 InboundMessage/OutboundMessage，禁止跨渠道直接调用对方 API
- channelsui 中不存在的 WebUI 能力以空实现或回退类（如 SimpleHttpRouter、MediaService）提供，保证 websocket 渠道可独立运行
- WebSocket 客户端鉴权采用一次性短命 token（WebSocketTokenIssuer），会话级工作区范围通过 WorkspaceScope 快照传递
