- 所有可调阈值（token_threshold、heartbeat_interval_s、reasoning_delta_min_interval_s、stream_retry_delay_s、tool_timeout_seconds、goal_max_continuations）均通过模块级 `_override(name)` 函数读取，优先返回 sys.modules[__name__] 上的同名覆盖值，否则回退到 get_env_config()。
- 对外部可失败 I/O（run manifest 写入、LLM usage artifact 写入、sandbox home 创建、mootdx 配置拷贝等）统一使用 try/except 包裹并记录 warning/debug 日志，保证异常不中断主循环。
- 关键状态文件（state.json、req.json、llm_usage.json）采用 write tmp + replace 或 open('wb') + flush + os.fsync 的方式写入，避免崩溃导致截断。
- 工具通过继承 `BaseTool` 并实现 `execute(**kwargs) -> str` 注册到 `ToolRegistry`，返回值统一为 JSON 字符串，错误路径也返回包含 status/error 的 JSON。
- 消息列表压缩以原地 mutate 方式实现（_microcompact/_context_collapse/_fix_tool_pairs），并按 token 估算阈值逐级触发，保持最近 N 条完整、折叠旧文本中间段。
- 子进程执行前通过白名单集合 `_RUNTIME_ENV_KEYS` 与 `_PROXY_ENV_KEYS` 过滤环境变量，显式注入 PYTHONUNBUFFERED/PYTHONIOENCODING 等安全键，并将当前 run_dir 追加到 VIBE_TRADING_ALLOWED_RUN_ROOTS。
