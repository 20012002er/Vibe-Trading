- 外部可选依赖采用延迟 import + try/except 包裹（如 yfinance、tushare、ccxt、requests），失败时返回 `status="skipped"` 而非抛出异常。
- 所有对外数据装载函数对缺失文件或非法内容都返回空集合/空字典（如 `load_json_file`、`load_csv_records`、`_load_ohlcv_artifacts`），保证调用方无需判空分支。
- 运行时状态推断通过检查 `runs/<id>/` 下特定文件是否存在（如 `state.json`、`metrics.csv`、`signal_engine.py`、`design_spec.json`）来判定 run stage，而非依赖外部状态服务。
- 市场数据源选择使用集中式的正则模式表 `_SOURCE_PATTERNS` 按符号后缀匹配首选 source，再通过 registry 的 fallback chain 自动降级。
- 数值字段统一通过 `_safe_float` 或 `_json_safe` 转换，将 None/空串/NaN 归一化为 None，确保下游 JSON 序列化安全。
