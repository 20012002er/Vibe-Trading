新增工具只需在 `src/tools/` 下创建 `xxx_tool.py` 并继承 `BaseTool` 即可被自动发现；若工具依赖可选库需重写 `check_available() -> False` 以静默排除。启用 shell 工具需显式传入 `include_shell_tools=True`，否则 `bash`/`background_run`/`cancel_background` 默认禁用。配置 MCP 服务器后需在桌面会话运行 `vibe-trading connector authorize <profile>` 完成 OAuth 授权，否则 live broker 工具会被跳过。
