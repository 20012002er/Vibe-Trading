- 每个工具独立一个 `*_tool.py` 文件，定义继承 `BaseTool` 的类，声明 `name`、`description`、`parameters`（JSON Schema）、`execute(**kwargs) -> str` 四个必要成员。
- 工具通过 `__init__.py` 的 `build_registry()` 自动发现注册，无需手动 import 或维护清单。
- 对外部可选依赖采用延迟 import + `check_available()` 模式，缺失时记录日志并跳过该工具而非抛出异常。
- 返回结果统一为 JSON 字符串，成功用 `{"status": "ok", ...}`，失败用 `{"status": "error", "error": "..."}`，便于上层解析。
- 涉及 shell 执行的工具调用前通过 `_shell_safety.broad_python_kill_error` 检查，拒绝可能杀死宿主 Python 进程的宽泛 kill 命令。
- 所有进入事件流、trace 或审计账本的参数与结果均经 `redaction.redact_payload` / `redact_tool_result` 脱敏，区分 ARGUMENTS_SINK 与 RESULT_SINK 两套敏感键集合。
