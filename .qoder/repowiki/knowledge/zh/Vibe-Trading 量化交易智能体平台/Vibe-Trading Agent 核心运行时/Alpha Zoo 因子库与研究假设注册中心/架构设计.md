模块由两个并列子系统组成：
- `factors/`：以 `base.py` 定义宽表 DataFrame 算子契约（`ts_mean/ts_std/ts_corr/ts_rank/delta/safe_div/vwap` 等），所有 zoo 因子通过 `zoo/<zoo_id>/<id>.py` 中的 `__alpha_meta__` 字面量声明元数据并由 `registry.Registry` 在启动时 AST 扫描发现；`Registry.compute` 惰性 import 对应模块并调用其 `compute(panel)`，输出经 `_validate_output` 做形状/inf/nan 校验；`cli_handlers.py` 暴露 `list/show/bench/compare/export-manifest` 五个子命令，分别委托 `bench_runner` / `bench_runner_strict` / `compare_runner` 完成 IC 回测与 HTML 报告生成。
- `hypotheses/`：纯代码的轻量注册中心，`Hypothesis` dataclass + `HypothesisRegistry` 将研究假设持久化到 `~/.vibe-trading/hypotheses.json`（可通过 `VIBE_TRADING_HYPOTHESES_PATH` 覆盖），支持 create/update/link_backtest/search/list 及 `list/show/invalidate` CLI；状态机限定为 `exploring/testing/validated/rejected/monitoring` 五态。
依赖方向单向：CLI → registry → zoo 模块；hypotheses 子系统独立于 factors，仅通过上层 `agent/cli.py` 统一挂载子命令。
